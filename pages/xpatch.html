What is xPatch?

xPatch is a simple to use tool for creating xDelta patches.

What is a xDelta patch?

An xdelta patch is a file that stores the differences between two binary files, rather than the full file itself. It's built using the xdelta algorithm (a binary diff/patch tool), and is commonly used in retro gaming and ROM hacking communities.
