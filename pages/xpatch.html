xPatch

What is xPatch?

xPatch is a simple-to-use tool designed for easily creating xDelta patches.

What is an xDelta Patch?

An xDelta patch is a file that stores only the differences between two binary files, rather than containing the entire file itself. Built using the xDelta algorithm (a binary diff/patch tool), it is widely used throughout the retro gaming and ROM hacking communities for distributing modifications safely and efficiently.
