Vital Skins

How to add skins to Vital:
  1. Download the .vitaltheme / .vitalskin file from the link provided.
  2. Open Vital and click the "Advanced" tab.
  3. At the bottom of the "Advanced" tab, you will see a section called "Skin".
  4. Select "Load Custom Theme..." and then select the .vitaltheme / .vitalskin file you downloaded.
