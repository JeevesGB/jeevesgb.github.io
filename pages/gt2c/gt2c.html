Gran Turismo 2 Concept

About

Gran Turismo 2 Concept is a fan-made modification of the original Gran Turismo 2 game for the PlayStation. This project redesigns the menus to resemble those of Gran Turismo 3, while also introducing new cars and events for players to enjoy.

Features

  • Redesigned menus inspired by Gran Turismo 3
  • Reworked main menu
  • New cars added to the roster
  • Additional racing events and challenges (coming soon)

Download and Installation

Download the test build patch and the xPatch tool below. Gran Turismo 2 v1.2 NTSC disc image is required.

GT2 Concept Test Build .xDelta Patch
xPatch (xDelta Patcher)

How To Patch

  1. Download and run xPatch.
  2. Select your Gran Turismo 2 v1.2 NTSC disc image as the source file (make a backup first!).
  3. Select the provided .xdelta patch file.
  4. Choose an output location and filename for the patched game.
  5. Start the patching process.
  6. Load the patched game in your emulator or console.
