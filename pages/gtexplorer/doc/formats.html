TIM Pack format (COURSE / BG)

Offset  Size   Description
0x00    4      Number of TIMs (uint32 LE)
0x04    20×N   Directory:
                 16 bytes  Name (null-padded ASCII)
                  4 bytes  Offset of TIM data (uint32 LE)
…       …      TIM blobs at listed offsets
