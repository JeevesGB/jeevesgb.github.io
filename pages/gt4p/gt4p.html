How to Patch

Note: You must use Gran Turismo 4 Online Public Beta. Other versions will not work.

  1. Download an xDelta patcher (xdeltaUI or xdelta3 recommended).
  2. Make a backup of your original Gran Turismo 4 Online Public Beta SCUS_974.36 disc image.
  3. Run the patcher and select your original disc image as the source file.
  4. Select the provided .xdelta patch file.
  5. Choose an output location and filename for the patched game.
  6. Start the patching process.
  7. Once complete, load the patched game.
