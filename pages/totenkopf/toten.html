Totenkopf

About the Mod

Totenkopf is a Hard Mode Mod for Return to Castle Wolfenstein. All map .ai scripts have been edited along with various UI and loading screen enhancements to elevate the challenge.

How To Run

  1. Download the mod from the official GitHub repository below.
  2. Make a backup copy of your Return to Castle Wolfenstein installation.
  3. Place _totenkopf.pk3 directly into your RTCW/Main directory.
  4. [Optional] Download the autoexec.cfg file and place it in the same RTCW/Main directory.
