Totenkopf is a Hard Mode Mod for Return To Castle Wolfenstein.
All map .ai scripts have been edited along with some UI and load screen tweaks.

How To Run

1. Download the mod from the linked GitHub below.

2. Make a copy of your RTCW installation.

3. Place _totenkopf.pk3 in your RTCW/Main directory.

4. [Optional] Download the autoexec.cfg file and place it in the RTCW/Main directory.
